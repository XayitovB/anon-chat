# 💬 Anon Chat

Anonymous Telegram chat bot — smart user matching, ratings, premium filters, and friends system.

![Python](https://img.shields.io/badge/Python-3.8+-3776AB?style=flat&logo=python&logoColor=white)
![aiogram](https://img.shields.io/badge/aiogram-3.x-26A5E4?style=flat&logo=telegram&logoColor=white)
![License](https://img.shields.io/github/license/XayitovB/anon-chat?style=flat)

## Features
- Full anonymity with secure message forwarding
- Smart matching by gender & age (premium)
- 1–5 star rating system after each session
- Add friends after conversations
- Premium via Telegram Stars — priority matching & advanced filters
- Admin panel: statistics, broadcasts, user bans
- Rate limiting, input validation, abuse reporting

## Quick Start
```bash
cp .env.example .env
pip install -r requirements.txt
python bot.py
```

## Stack
`Python 3.8+` · `aiogram 3` · `SQLite` · `Telegram Stars`
